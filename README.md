# 병원한걸음

혼자 병원 가는 어르신과 교통약자를 위한 **동행 신청 안내 + 한 걸음 음성 길안내** 모바일 웹앱
(미금역 → 마을버스 7-1번 → 분당서울대병원 1동 1층 처음오신 창구)

## 실행

```bash
python3 server.py
```
→ http://localhost:8000

AI 해석과 더 자연스러운 AI 목소리를 쓰려면 실행 전에 OpenAI 키를 넣어 주세요 (선택):
```bash
export OPENAI_API_KEY=sk-...
```
키가 없어도 앱은 기기 안 규칙 해석 + 기기 내장 한국어 목소리로 끝까지 동작합니다.

## 휴대폰에서 GPS 쓰기
휴대폰 브라우저는 **https 주소**에서만 위치·방향 센서를 허용합니다.
GitHub Pages, Netlify 같은 곳에 올리거나 터널(https)로 열어 주세요.
실내 시연에서는 ⚙︎ 설정 → **시연 모드**를 켜면 GPS 없이 걸어가는 것처럼 화살표와 거리가 움직입니다.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 큰 글씨 화면, 하단 고정 버튼 |
| `app.js` | 음성 인식·읽기, AI 4항목 정리, GPS+나침반 화살표, 실내 안내, 도움 요청 카드 |
| `route.js` | 경로 데이터 — **현장 답사 후 좌표·표지판 문구·verified 를 실제 값으로 바꾸세요** |
| `server.py` | (선택) OpenAI 중계: `/api/parse`, `/api/tts` |

## 처음 열 때: 위치 · 마이크 켜기
첫 화면에서 **“한 번에 모두 켜기”**를 누르고 휴대폰이 물으면 **허용**을 누르세요.
거부했을 때는 화면에 아이폰/안드로이드별로 다시 켜는 방법이 나옵니다. (⚙︎ 설정 → “위치·마이크 켜기”로 언제든 다시 열 수 있어요)
카카오톡 안에서 열면 안 될 수 있으니 **Safari / Chrome으로 열어** 주세요.

`qr.png` (또는 배포 주소의 `/qr.html` — 발표·인쇄용 큰 화면)

## 마이크가 안 될 때
- 노란 버튼으로 바로 듣기가 안 되면 자동으로 **키보드 🎤 받아쓰기** 화면이 열립니다 (거의 모든 휴대폰에서 동작).
- iPhone: 설정 → Safari → 마이크 ‘허용’, 설정 → 일반 → 키보드 → ‘받아쓰기 활성화’
- Android: Chrome 주소창 왼쪽 버튼 → 권한 → 마이크 ‘허용’ (삼성 인터넷은 바로 듣기를 지원하지 않아 키보드 받아쓰기로 동작)

## 지도에서 목적지 고르기
“어디로 갈까요?” 화면에서 지도를 누르거나, 이름(또는 🎙 말로)으로 찾으면 그곳까지 GPS 화살표로 안내합니다.
(지도: OpenStreetMap · 검색: Nominatim. 직선 방향 안내이므로 실제 길은 조금 다를 수 있어요.)
분당서울대병원은 현장 답사한 **미금역 → 7-1번 → 1동 → 처음오신 창구** 경로로 안내합니다.

## 🩺 진료 메모 (선생님 말씀 쉽게 요약)
위쪽 **🩺 진료 메모** 버튼 → 선생님께 동의 문장을 보여 드린 뒤 **받아 적기 시작** → 끝나면 **다 들었어요**.
- 조용하면 꺼지는 휴대폰 음성 인식을 자동으로 다시 켜서 긴 말씀도 이어서 받아 적습니다.
- 정리 칸: ⚠️ 꼭 조심하세요 / 💊 약 드시는 법 / 📅 다음에 오실 때 / 🧪 검사 / 🩺 몸 상태, 어려운 말은 쉬운 말로 풀어 줍니다.
- 서버 키가 있으면 GPT-4o-mini가, 없으면 휴대폰 안 규칙으로 정리합니다. **자동 정리라 틀릴 수 있으니 약·날짜는 꼭 다시 확인.**
- 🔊 들려주기, 📤 가족에게 보내기(공유). 소리 파일은 만들지 않고 글은 저장하지 않습니다.

## 🚌 7-1번 실시간 도착 (경기도 버스정보)
길안내 2·3단계(정류장 가기, 버스 타기)에 “7-1번 약 N분 뒤 · M정거장 전 · ♿ 저상버스”를 30초마다 보여 주고 읽어 줍니다.
같은 서울대병원 방향 다른 버스(2번, 7번 등)도 함께 알려 줍니다. 버스에 타면 자동으로 숨깁니다.
- 정류장·노선은 경기도 버스정보 API로 확인: 7-1번(노선ID 241222004) **미금역3번출구(마을)**(206000852) 출발 → 4번째 **서울대병원**(206000261)
- 키: data.go.kr **경기도_버스도착정보 조회** 활용신청 → `.env` 의 `DATA_GO_KR_KEY`

## 👪 보호자 연결 · 알림
⚙︎ 설정 → 👪 보호자, 또는 첫 화면의 “보호자(가족) 번호 등록하기”. 최대 3명, **번호는 이 휴대폰에만 저장**(‘처음부터 다시’에도 유지).
- 길 안내 시작 · 버스 하차 · 병원 도착 · 창구 도착 · 진료 메모 · 도움 요청/119 때 “보호자에게 알릴까요?” 판이 뜸 (순간별로 켜고 끄기)
- 📩 문자: 문자 앱이 보낼 내용(시간 + 카카오맵 현재 위치 링크)이 채워진 채 열리고 **보내기는 직접** 누름 · 📞 전화 · 💬 카카오톡 공유
- 웹앱은 몰래 자동으로 문자를 보낼 수 없어요. 자동 발송은 유료 문자 API + 서버가 필요합니다.

## 🏥 가까운 병원 · 🚑 응급실
첫 화면의 버튼, 🚨 119 화면, 지도 고르기 화면에서 열 수 있어요. 거리순 목록 + 지도 번호 + 📞 전화 + 🧭 길 안내.
- **공공데이터 키가 연결되면**: 국립중앙의료원 병·의원/응급의료기관 위치 정보 (+ 가능하면 응급실 빈 침대 수)
- **키가 없으면**: OpenStreetMap 무료 데이터 (응급실 운영 여부는 전화로 확인 안내)

### 공공데이터 키 연결 (키는 절대 웹앱 파일에 넣지 않기)
1. data.go.kr 에서 **국립중앙의료원_전국 병·의원 찾기 서비스**, **국립중앙의료원_전국 응급의료기관 정보 조회 서비스** 활용 신청
2. 컴퓨터에서 쓸 때: 이 폴더에 `.env` 파일을 만들고 `DATA_GO_KR_KEY=받은키` → `python3 server.py`
3. 휴대폰(GitHub Pages)에서 쓸 때: `worker.js` 를 Cloudflare Workers 에 올리고 키를 secret 으로 저장 → `config.js` 의 `apiBase` 에 주소 입력

## 목소리
- 서버에 키가 있으면 `gpt-4o-mini-tts` 의 따뜻한 목소리(설정에서 “AI 자연 음성”)
- 없으면 기기에서 가장 자연스러운 한국어 목소리를 자동 선택 (Natural/Online/Premium/Siri/Google 순)
- iPhone: 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 한국어 에서 **유나(향상됨)** 를 내려받으면 훨씬 자연스러워집니다.
