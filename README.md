# 병원한걸음

혼자 병원 가는 어르신과 교통약자를 위한 **동행 신청 안내 + 한 걸음 음성 길안내** 모바일 웹앱
(미금역 → 마을버스 7-1번 → 분당서울대병원 1동 1층 처음오신 창구)

## 실행

```bash
python3 server.py
```
→ http://localhost:8000

AI 해석과 더 자연스러운 AI 목소리를 쓰려면 실행 전에 OpenAI 키를 넣어 주세요 (선택):
```bash
export OPENAI_API_KEY=sk-...
```
키가 없어도 앱은 기기 안 규칙 해석 + 기기 내장 한국어 목소리로 끝까지 동작합니다.

## 휴대폰에서 GPS 쓰기
휴대폰 브라우저는 **https 주소**에서만 위치·방향 센서를 허용합니다.
GitHub Pages, Netlify 같은 곳에 올리거나 터널(https)로 열어 주세요.
실내 시연에서는 ⚙︎ 설정 → **시연 모드**를 켜면 GPS 없이 걸어가는 것처럼 화살표와 거리가 움직입니다.

## 처음 열 때: 위치 · 마이크 켜기
첫 화면에서 **“한 번에 모두 켜기”**를 누르고 휴대폰이 물으면 **허용**을 누르세요.
거부했을 때는 화면에 아이폰/안드로이드별로 다시 켜는 방법이 나옵니다. (⚙︎ 설정 → “위치·마이크 켜기”로 언제든 다시 열 수 있어요)
카카오톡 안에서 열면 안 될 수 있으니 **Safari / Chrome으로 열어** 주세요.

## 마이크가 안 될 때
- 노란 버튼으로 바로 듣기가 안 되면 자동으로 **키보드 🎤 받아쓰기** 화면이 열립니다 (거의 모든 휴대폰에서 동작).
- iPhone: 설정 → Safari → 마이크 ‘허용’, 설정 → 일반 → 키보드 → ‘받아쓰기 활성화’
- Android: Chrome 주소창 왼쪽 버튼 → 권한 → 마이크 ‘허용’ (삼성 인터넷은 바로 듣기를 지원하지 않아 키보드 받아쓰기로 동작)

## 지도에서 목적지 고르기
“어디로 갈까요?” 화면에서 지도를 누르거나, 이름(또는 🎙 말로)으로 찾으면 그곳까지 GPS 화살표로 안내합니다.
(지도: OpenStreetMap · 검색: Nominatim. 직선 방향 안내이므로 실제 길은 조금 다를 수 있어요.)
분당서울대병원은 현장 답사한 **미금역 → 7-1번 → 1동 → 처음오신 창구** 경로로 안내합니다.

## 🩺 진료 메모 (선생님 말씀 쉽게 요약)
위쪽 **🩺 진료 메모** 버튼 → 선생님께 동의 문장을 보여 드린 뒤 **받아 적기 시작** → 끝나면 **다 들었어요**.
- 조용하면 꺼지는 휴대폰 음성 인식을 자동으로 다시 켜서 긴 말씀도 이어서 받아 적습니다.
- 정리 칸: ⚠️ 꼭 조심하세요 / 💊 약 드시는 법 / 📅 다음에 오실 때 / 🧪 검사 / 🩺 몸 상태, 어려운 말은 쉬운 말로 풀어 줍니다.
- 서버 키가 있으면 GPT-4o-mini가, 없으면 휴대폰 안 규칙으로 정리합니다. **자동 정리라 틀릴 수 있으니 약·날짜는 꼭 다시 확인.**
- 🔊 들려주기, 📤 가족에게 보내기(공유). 소리 파일은 만들지 않고 글은 저장하지 않습니다.

## 🚌 7-1번 실시간 도착 (경기도 버스정보)

## 새 기능 (첫 화면 바로가기 타일)
- **📷 여기가 어디?**: 표지판·간판 사진 → 휴대폰 안에서 글자 읽기(Tesseract.js, 처음 한 번 글자 사전 내려받기) → 아는 표지판이면 할 일 안내. 서버 AI가 있으면 GPT-4o-mini가 사진을 보고 안내.
- **🎙 말로만 하기**: 화면 오른쪽 아래 마이크 / 설정의 ‘말로만 하기’를 켜면 안내가 끝날 때마다 자동으로 들음. “다 왔어요, 버스 언제 와, 도와줘, 여기 어디야, 택시, 몇 시에 나가, 딸한테 연락, 응급실, 119 …”
- **🚕 택시 타기**: 기사님께 보여 줄 큰 글씨 카드(목적지·보행기/휠체어), 카카오 T 열기, 경기도 광역이동지원센터(1666-0420, 공식 안내로 재확인 필요)
- **⏰ 몇 시에 나갈까**: 진료 시간(말로도 가능: “내일 10시 반”) → 걸음 속도·버스 대기·접수·첫 방문 여유를 더해 출발 시각 계산, 📅 달력 알림(.ics: 하루 전·30분 전·출발 때)
- **🌐 외국어·필담**: 영어·중국어·베트남어·일본어·러시아어 문장 카드(한국어 크게 + 내 말), 해당 언어로 읽기 / 🧏 필담: 크게 쓰기, 직원 말을 글자로
- **📡 보호자 실시간 위치 보기**: 보호자 화면에서 켜기 → `family.html#…` 링크를 보호자에게 전송. 위치는 휴대폰에서 AES-GCM으로 암호화해 ntfy.sh(무료 중계)에 올리고, 열쇠는 링크의 # 뒤에만 있어 중계 서버도 못 읽음. 6시간 뒤 자동 꺼짐, 링크 새로 만들기로 예전 링크 차단.

## 🚏 버스 정류장 안내 (처음 화면 타일 · ☰ 메뉴 · “정류장”이라고 말하기)

### 지금 정류장 · 버스 탄 뒤 · 지하철 (처음 화면 ‘🚏 버스·지하철’)
- **버스 키가 없어도** 주변 정류장 위치는 보여요(OpenStreetMap). 실시간 도착은 설정 QR/키가 있을 때.
- **📍 지금 계신 정류장**: 정류장 바로 앞(약 60m)이면 자동으로 알려 주고 오는 버스 보기로 연결
- **버스 번호를 누르면 → 내릴 곳 고르기 → 타고 가는 동안** “지금 ○○ · 내릴 곳까지 N정거장”, 한 정거장 전 “하차 벨 누르세요”, 도착 “지금 내리세요” (진동+음성). GPS가 약하면 ‘한 정거장 지났어요’ 버튼
- 길안내 7-1번 단계에도 같은 ‘몇 정거장 남았는지’ 카드
- **🚇 지하철역 탭**: 가까운 역(약 3km) → 역을 누르면 **출구 번호·엘리베이터**를 가까운 순으로, 누르면 그 출구까지 길 안내 (OpenStreetMap). 실시간 열차 시간은 서울시 실시간 지하철 API 키 + 중계 서버가 필요해 아직 없음

## 🧭 가는 길 (먼 곳은 걷지 않게)
병원 검색·지도 고르기·역·정류장에서 고른 곳이 **900m보다 멀면** “어떻게 갈까요?” 화면:
- **🚌 한 번에 가는 버스** (경기도 버스정보): 주변 정류장에 오는 버스들의 노선을 확인해 목적지 900m 안에 서는 버스를 찾고, 걷기+기다림+정거장 수로 빠른 순 추천 → 누르면 **정류장까지 걷기 → 버스(남은 정거장·하차 알림) → 목적지까지 걷기** 전체 안내
- **🚇 지하철·갈아타기**: 카카오맵/네이버 지도 대중교통 길찾기로 연결(앱 있으면 앱, 없으면 웹). 8km 넘으면 이 버튼을 먼저 보여 줌
- 🚶 걸어서(2km 이하일 때만) · 🚕 택시
- 앱 안에서 갈아타기·지하철까지 안내하려면 ODsay 같은 대중교통 길찾기 API 키가 필요해요.

## 🏥 병원 안 안내 (처음 화면 타일 · 창구 도착 화면)
- **진료 순서**를 한 단계씩: 접수 → 진료과 앞 대기 → 진료 → 수납 → 약 받기 → 다음 예약 (단계마다 할 일·찾아볼 표지판 글자·직원 카드·관련 기능 연결)
- **병원 안에서 찾기**: 처음오신 창구 · 진료과 · 수납 · 피/사진 검사 · 화장실 · 엘리베이터 · 안내 데스크 · 나가는 곳
- 층·방 번호는 병원마다 달라 지어내지 않아요. 현장 답사로 확인한 곳은 `route.js`에 `insidePlaces: { toilet: { steps: ["…", "…"] } }`처럼 넣으면 “현장 확인함” 안내가 먼저 나와요.

## 🔍 병원 검색 (처음 화면 ‘병원 찾기·응급실’)
- 처음 화면에도 **🔍 병원 이름으로 찾기** 검색창
- 이름 검색은 줄임말(서울대병원→분당서울대학교병원, 차병원→분당차병원)·띄어쓰기·오타(분당채병원)도 찾고, 글자 칠 때 주변 병원 추천 목록이 떠요 (Photon → Nominatim 순서로 찾고, 한쪽이 막혀도 다른 쪽으로)
- 검색창: 병원 이름(예: 분당차병원) 또는 진료과(예: 안과) · 진료과 버튼(내과·정형외과·안과·이비인후과·치과·피부과·한의원·약국 …)
- 🎙 말로 찾기: “근처 안과 찾아줘”, “무릎이 아파요”(→ 정형외과), “이가 아파”(→ 치과), “약국 어디 있어”
- 결과는 내 위치에서 가까운 순 · 지도 번호 · 📞 전화 · 🧭 길 안내
- 진료과는 주변(약 3km→8km) 병·의원을 OpenStreetMap에서 모아 이름·진료과 정보로 걸러 찾음 (등록 안 된 병원은 안 나올 수 있음)

## 🏥 가까운 병원 · 🚑 응급실
첫 화면의 버튼, 🚨 119 화면, 지도 고르기 화면에서 열 수 있어요. 거리순 목록 + 지도 번호 + 📞 전화 + 🧭 길 안내.
- **공공데이터 키가 연결되면**: 국립중앙의료원 병·의원/응급의료기관 위치 정보 (+ 가능하면 응급실 빈 침대 수)
- **키가 없으면**: OpenStreetMap 무료 데이터 (응급실 운영 여부는 전화로 확인 안내)

### 공공데이터 키 연결 (키는 절대 웹앱 파일에 넣지 않기)
1. data.go.kr 에서 **국립중앙의료원_전국 병·의원 찾기 서비스**, **국립중앙의료원_전국 응급의료기관 정보 조회 서비스** 활용 신청
2. 컴퓨터에서 쓸 때: 이 폴더에 `.env` 파일을 만들고 `DATA_GO_KR_KEY=받은키` → `python3 server.py`
3. 휴대폰(GitHub Pages)에서 쓸 때: `worker.js` 를 Cloudflare Workers 에 올리고 키를 secret 으로 저장 → `config.js` 의 `apiBase` 에 주소 입력

## 목소리
- 서버에 키가 있으면 `gpt-4o-mini-tts` 의 따뜻한 목소리(설정에서 “AI 자연 음성”)
- 없으면 기기에서 가장 자연스러운 한국어 목소리를 자동 선택 (Natural/Online/Premium/Siri/Google 순)
- iPhone: 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 한국어 에서 **유나(향상됨)** 를 내려받으면 훨씬 자연스러워집니다.
