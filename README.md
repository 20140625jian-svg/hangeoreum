# 병원한걸음

혼자 병원 가는 어르신과 교통약자를 위한 **동행 신청 안내 + 한 걸음 음성 길안내** 모바일 웹앱
(미금역 → 마을버스 7-1번 → 분당서울대병원 1동 1층 처음오신 창구)

## 실행

```bash
python3 server.py
```
→ http://localhost:8000

AI 해석과 더 자연스러운 AI 목소리를 쓰려면 실행 전에 OpenAI 키를 넣어 주세요 (선택):
```bash
export OPENAI_API_KEY=sk-...
```
키가 없어도 앱은 기기 안 규칙 해석 + 기기 내장 한국어 목소리로 끝까지 동작합니다.

## 휴대폰에서 GPS 쓰기
휴대폰 브라우저는 **https 주소**에서만 위치·방향 센서를 허용합니다.
GitHub Pages, Netlify 같은 곳에 올리거나 터널(https)로 열어 주세요.
실내 시연에서는 ⚙︎ 설정 → **시연 모드**를 켜면 GPS 없이 걸어가는 것처럼 화살표와 거리가 움직입니다.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 큰 글씨 화면, 하단 고정 버튼 |
| `app.js` | 음성 인식·읽기, AI 4항목 정리, GPS+나침반 화살표, 실내 안내, 도움 요청 카드 |
| `route.js` | 경로 데이터 — **현장 답사 후 좌표·표지판 문구·verified 를 실제 값으로 바꾸세요** |
| `server.py` | (선택) OpenAI 중계: `/api/parse`, `/api/tts` |

## 목소리
- 서버에 키가 있으면 `gpt-4o-mini-tts` 의 따뜻한 목소리(설정에서 “AI 자연 음성”)
- 없으면 기기에서 가장 자연스러운 한국어 목소리를 자동 선택 (Natural/Online/Premium/Siri/Google 순)
- iPhone: 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 한국어 에서 **유나(향상됨)** 를 내려받으면 훨씬 자연스러워집니다.
